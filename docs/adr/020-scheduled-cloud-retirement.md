# ADR 020 — 클라우드 종료와 증빙 보존 경계

- Why: 기간 한정 클라우드 사용 종료 때 잔존 과금 자원과 증빙 손실을 함께 방지해야 한다.
- What: 사용자가 지정 프로젝트 전체(기존 자원 포함) 종료 기한을 2026-11-01 23:00 KST로 확정했다.
- How: 계정별 목록·삭제 계획·원자료는 private/에 두고, 반출·복원·전수 조회·외부 예약 실행기 검증 뒤 정리한다.
- How: 현재 구현은 로컬 증거의 프로젝트 범위·신선도·경로·hash 검사만 하며 실제 삭제와 예약은 미구현이다.
- Trade-off: API 비활성·권한·보존 정책·예약 환경 blocker를 자동 우회하지 않는다. 미확인은 삭제 가능으로 취급하지 않는다.
- 기각: VM 종료만으로 정리 완료, 예산 알림만으로 과금 차단, 증거 없는 자동 삭제, 공급자 보존 기간을 영구 삭제 완료로 표시.
- 완료 구분: 자원 삭제·결제 해제·프로젝트 종료 요청과 공급자 영구 삭제·지연 사용료 확인을 각각 기록한다.
