# ADR 007 — v3 동결 표본 종료
- Why: 최근 5개를 먼저 고정한 뒤 모드를 필터해 425개 중 332개가 제외됐다.
- Why: 최종 평가 24명·80건은 사전 최소치 59명·150건에 각각 35명·70건 미달했다.
- What: 425개 전량 처리·DQ PASS 후 결론을 `INTERMEDIATE`로 동결한다.
- How: 1차 0/24, 2차 0/80·Wilson 95% 0~4.58%와 모든 스킵 분모를 그대로 발행한다.
- Boundary: 현 표본에 match를 보충하거나 룰·임계값·완료 기준을 바꾸지 않는다.
- Trade-off: 사전 계획 무결성은 지키지만 5% 운영 기준을 지지하는 결론은 얻지 못한다.
- Rejected: 완료 기준 하향, 결과 확인 후 현 run 표본 확장, 혼합 모드 통합.
