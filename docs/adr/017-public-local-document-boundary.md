# ADR 017: 공개 문서와 로컬 전달 자료 경계
- Why 문제: 대상별 전달 서술이 기술 정본에 섞이면 공개 범위와 전달 범위를 구분할 수 없다.
- What 결정: Git 추적 경로에는 코드, 기술 계약과 재현 결과만 두고 대상별 자료는 로컬 `private/`에 둔다.
- How 구현: `/private/` ignore, 공개 링크 제거, 추적 파일 문자열 검사로 경계를 확인한다.
- 기각한 대안: 공개 문서 내부의 비표시 주석과 파일명 규칙은 Git 이력 노출을 막지 못한다.
- Trade-off: 로컬 자료는 clone으로 복원되지 않지만 공개 정본과 전달 서술의 결합을 차단한다.
- 상태: ACCEPTED, 코드 계약과 룰, 임계값 변경 없음.
